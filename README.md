# Планировщик задач
 
Веб-сервер на Go — REST API для планировщика задач с поддержкой периодических напоминаний.
 
## Возможности
 
- Добавление, редактирование, удаление задач
- Отметка задач как выполненных с автоматическим переносом даты
- Правила повторения: по дням, неделям, месяцам, годам
- Поиск по тексту и по дате
- Аутентификация по паролю (JWT)
## Запуск
 
```bash
go run main.go
```
 
Откройте в браузере: `http://localhost:7540/`
 
**Переменные окружения** (опционально):
 
| Переменная | Назначение |
|---|---|
| `TODO_PORT` | порт сервера |
| `TODO_DBFILE` | путь к файлу БД |
| `TODO_PASSWORD` | пароль для входа |
 
## Тесты
 
```bash
go test ./tests
```
 
Если задан `TODO_PASSWORD`, скопируйте токен из куки `token` в `tests/settings.go` (переменная `Token`).
 
## Docker
 
```bash
mkdir -p data
docker build -t todo-app .
docker run -d -p 7540:7540 -v $(pwd)/data:/app/data -e TODO_PASSWORD=12345 todo-app
```
 
## Реализованные задания со звёздочкой
 
- Порт и путь к БД через переменные окружения

- Поиск задач
